UPSTREAM
Coffee from the cup back to the roaster: a chemistry-first course
=================================================================

HOW TO OPEN
  Double-click index.html. The book opens in your web browser.
  Nothing is installed and no internet connection is needed.

WHAT YOU NEED
  Any of these browsers or later:
    Internet Explorer 6 (Windows 98, 2000, XP)
    Firefox 1.5, Opera 9, Safari 2, Konqueror 3.5
    Text browsers such as Lynx, Links or w3m (calculators show formulas only)
  About 2 MB of disk space. Any processor that runs one of the browsers above.
  The pages use only fonts supplied with Windows XP and Mac OS X.

IF INTERNET EXPLORER SHOWS A YELLOW BAR
  Older versions of Internet Explorer warn about scripts in local files.
  The pages are marked to avoid this, but if a bar appears, choose
  "Allow blocked content". The calculators and self-checks need it;
  the text does not.

PRINTING
  Open print.html for the whole book on one page, then print.
  Calculator buttons, the brewing chart and links to solutions are hidden
  on paper. Worked solutions are on each chapter's solutions page.

FLASHCARDS
  flashcards.txt holds every defined term and self-check question.
  In Anki choose File > Import and pick the file; no settings are needed.

DARK MODE
  On a computer set to dark mode, current browsers show light text on a
  dark background. Older browsers and printouts are unaffected.

COPYING TO OTHER MEDIA
  The folder can be copied to a USB stick, CD-ROM or network share and
  opened from there. Keep all files in the same folder.
